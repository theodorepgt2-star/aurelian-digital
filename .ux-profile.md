# UX profile: Aurelian Digital

## Aesthetic reference
Apple Native: generous spacing, unified radii, fluid transitions, neutral palettes.
Starfield dark theme (navy base, mint and jade accents) is the brand look; the baseline above governs spacing, radii, and motion restraint.

## Banned anti-aesthetics
- Glassmorphism or `backdrop-filter` blur without a clear high-contrast border
- Pastel pill badges around ordinary metadata
- Decorative gradients and glowing neon borders
- Multi-colour rainbow gradients on standard CTAs
- Cartoon people in empty states
- Icons inside input fields unless functional; nested scrollbars

## Accessibility target
WCAG 2.1 AA: 4.5:1 contrast for normal text, 3:1 for large text and borders, 44x44 px touch targets, visible focus rings.

## Brand tone and microcopy voice
Warm and human-centred: clear, empathetic, supportive. Short sentences, a concrete next step in every error or confirmation.

## Icon library
Lucide, chosen as the product icon set. Not installed yet; install only when needed. Do not mix icon sets and do not use emoji as UI icons.
Existing hand-written SVG icons in the service cards are to be replaced when Lucide is added.

## Viewports
Every layout must work at 375px and 1280px, with no page-level horizontal overflow.
